# v0.5.0 features

Reference for the modules and pipeline additions introduced in
v0.5.0. See `CHANGELOG.md` for the per-patch breakdown.

## Centroid refinement

The `hull_centroid` pipeline grew from 5 steps to 6, with a new
texture-space step 3b and a new anatomical-prior step 5.

### Step 3b — Gabor-edge body contour

`ForegroundDetector.gabor_body_contour(result, cx, cy, ...)` finds
the rat body outline using Canny edges on the Gabor energy map. The
body appears as a low-energy hole (smooth fur does not excite
bedding-frequency Gabor filters); edges on that map trace the actual
outline in texture space, independent of pixel intensity.

Two methods are tried:

1. **Canny on Gabor energy.** Normalise → blur → Canny → morph close
   → largest contour enclosing `(cx, cy)`.
2. **Gabor energy percentile threshold** (fallback when no closed
   contour). Within the foreground blob, pixels with Gabor energy
   below the `energy_pct` percentile are classified as body.

Enable in the pipeline with `--gabor-refine` (and `--canny-low T` /
`--canny-high T` for the hysteresis thresholds). Requires the
background to have been built with `--texture-suppress` so a Gabor
model is cached.

The refined mask updates both:
- the body-pixel list consumed by step 4 (ellipse fit), and
- the eroded blob mask consumed by step 5 (anatomical prior)

so downstream steps see the texture-refined region.

### Step 5 — anatomical Gaussian shape prior

`hull_centroid(..., P=, body_length_mm=, body_width_mm=, body_z_mm=)`
enables a soft anatomical prior. Algorithm:

```
5a. px/mm scale at the body position
    Back-project (ellipse_cx, ellipse_cy) onto the plane Z = body_z_mm
    via a 2x2 linear solve from P. Reproject (X+1, Y, body_z_mm) and
    (X, Y+1, body_z_mm); mean pixel-distance per 1-mm world step is
    the isotropic scale. Handles perspective.

5b. Gaussian axes
    σ_major = body_length_mm × px_per_mm / 3
    σ_minor = body_width_mm  × px_per_mm / 3

5c. Rotated 2D Gaussian centred at the ellipse-fit position, rotated
    by the ellipse orientation θ. Built over a ±3σ bounded ROI for
    O(body_area_px) compute.

5d. Weighted centroid of (foreground blob ∩ Gaussian prior)
```

CLI: `--body-length MM --body-width MM --body-z MM`. Off by default
(`--body-length 0`). The pipeline auto-loads `dlt_P0`/`dlt_P1` from
the calibration `.npz` when `--body-length > 0`.

## Trajectory refinement

### `kalman_filter_trajectory` (offline, RTS)

`rpimocap.reconstruction.triangulate.kalman_filter_trajectory(frames,
fps, max_speed_mm_s, max_accel_mm_s2, measurement_noise_mm,
outlier_sigma, rts_smooth)`.

6-state constant-velocity Kalman with discrete white-noise acceleration
process model and an optional RTS (Rauch-Tung-Striebel) backward
smoother. Replaces Gaussian smooth + linear gap-fill with:

- Mahalanobis-gate outlier rejection (`outlier_sigma`) — bad blob
  selections and reflections that slipped past the epipolar filter
  are rejected here. Flagged via the new `kalman_outlier` field on
  `Point3D`.
- Physics-constrained gap filling with constant-velocity predictions
  clamped to `max_speed_mm_s`.
- RTS backward pass for optimal offline smoothing.

CLI: `--kalman --kalman-fps FPS --kalman-max-speed MM_S
--kalman-max-accel MM_S2 --kalman-noise MM --kalman-outlier-sigma S
--kalman-no-rts`.

### `KalmanTracker3D` (online, per-frame)

`rpimocap.reconstruction.kalman.KalmanTracker3D` — same physics as
the offline version but designed for use inside the per-frame
detector loop. Single-target, 6-state, supports `step(z)` /
`predict()` / `update(z)` interfaces. Not yet wired into
`SegmentTracker._process_frame` — that's a follow-up.

## Detection improvements

### Temporal background adaptation

`BackgroundModel.update(frame0, frame1, mask0, mask1, alpha)` —
EMA-updates the background at pixels outside the foreground mask.
At α=0.995 (25 fps) the background has ~8 s memory; bedding the rat
moved earlier in the recording gradually becomes part of the new
background.

Wired into `SegmentTracker._process_frame`: adaptation runs only on
frames with a confirmed epipolar-validated match, and the foreground
mask is dilated by `bg_adapt_dilate_px` (default 25 px) before being
used so the animal's halo is excluded from the update.

CLI: `--bg-adapt-alpha A --bg-adapt-dilate-px PX`. Off by default.

### Trajectory-constrained blob selection

`EpipolarMatcher.match(..., prior0=, prior1=, prior_lambda=)` —
biases the global epipolar selector toward candidates near the
previous frame's confirmed centroid. A wall reflection with low
epipolar distance no longer wins over a slightly noisier blob near
the actual animal. The epipolar gate is still enforced.

CLI: `--trajectory-prior --trajectory-prior-lambda L`.

### Undistort before epipolar matching

`EpipolarMatcher(..., undistort_match=True)` — undistorts every
candidate centroid once upfront and uses undistorted coordinates for
line construction, distances, and the prior penalty. On a k1=-0.24
lens, the apparent epipolar distance for a true correspondence drops
from several pixels to <1 px, letting `max_epipolar_px` be tightened.

Default-on for new matchers.

### NIR vignette / flat-field correction

`rpimocap.detection.vignette` — three primitives:

- `load_flat_field(path)` — PNG/TIFF/NPZ loader
- `apply_flat_field(frame, ff)` — divide-and-rescale, brightness-
  preserving
- `synthesize_flat_field(bg)` — fits a smooth radial polynomial to
  the background image when no calibration capture exists

Wired symmetrically: the background is flat-fielded once at
construction, and every per-frame stereo pair is flat-fielded at the
top of `_process_frame`.

CLI: `--flat-field-cam0 PATH --flat-field-cam1 PATH
--synthesize-flat-field`.

## Posture detection

### `RearingClassifier`

`rpimocap.reconstruction.rearing.RearingClassifier` — stateful
classifier with hysteresis. Turns a 6-vector Kalman state into a
`PostureState(reared, z, vz, body_axis_horizontal, body_length_mm,
body_width_mm)`.

Two heuristics: enter reared state when `z > z_enter` (default
100 mm) or `vz > vz_enter` (default 200 mm/s); leave when
`z < z_exit` (default 70 mm). The vertical-posture anatomical prior
(90 × 45 mm by default) is meant to replace the horizontal one
(180 × 60 mm) during rear bouts — the hook into `GeometricLabeller`
is open for follow-up.

## Output schema

### `/skeleton/<name>/detected`

New boolean dataset in `reconstruction.h5`, written by `write_hdf5()`.

```
True  = genuine triangulated detection in this frame
False = gap-filled (linear interpolation, Kalman prediction,
        or Kalman outlier corrected to filter estimate)
```

Captured by the segment CLI immediately after
`results_to_skeleton_frames()` and before any smoothing, so post-
processing cannot corrupt it. Falls back to
`confidence > 0 AND NOT kalman_outlier` when no explicit mask is
supplied.

Reading:

```python
import h5py
with h5py.File("reconstruction.h5") as f:
    det = f["skeleton"]["animal"]["detected"][:]
    xyz = f["skeleton"]["animal"]["xyz"][:]
    xyz_real = xyz[det]   # only real detections for analysis
```
